# Olist 电商用户行为分析与 RFM 分层建模 (SQL + Python)

## 📖 项目背景
本项目基于巴西电商平台 Olist 的真实数据集（约 10 万条订单，9.3 万名真实用户），完成从**数据入库、SQL 业务指标计算、用户留存分析，到 Python 机器学习聚类（K-Means）**的完整数据挖掘与商业分析闭环。

## 🛠️ 技术栈与工具
- **数据库**：MySQL, Navicat
- **编程语言**：Python 3 (Pandas, Numpy, SQLAlchemy)
- **机器学习与统计**：Scikit-learn (StandardScaler, KMeans)
- **数据可视化**：Matplotlib, Seaborn (包含 2D/3D 绘图)
- **核心技能**：多表 JOIN、CTE (WITH)、窗口函数 (NTILE)、条件聚合 (CASE WHEN)、特征工程、无监督聚类。

## 📊 核心业务分析结论

### 1. 每日 GMV 与销售趋势
通过订单表和支付表关联，计算每日成交总额。数据显示平台销售额在 2017-2018 年呈显著上升趋势。

### 2. 区域销售分布
计算各省份销售额排名，发现 **SP（圣保罗州）** 是 Olist 的核心市场，销售额遥遥领先。这也与巴西的人口和经济分布高度吻合。

### 3. 用户留存与复购率洞察
- **次日/7日留存率为 0%**：通过 SQL 计算真实自然人的留存率，发现次日和7日留存率趋近于 0。
- **累计复购率约 3%**：放宽时间窗口后计算累计复购，发现仅约 3% 的用户会再次购买。
- **业务结论**：Olist 主营低频高客单价商品（家具、电器等），用户自然复购周期极长。因此，平台不宜追求“日活”，而应通过**提升客单价**或**拓展高频快消品类**来拉动增长。

### 4. 进阶：RFM 模型与 K-Means 用户分层
- **纯 SQL 视角**：使用窗口函数 `NTILE(5)` 结合 `CASE WHEN`，以相对排名的方式为用户的 R、F、M 三个维度打分（1-5分），直接通过 SQL 跑出业务分层标签。
- **机器学习视角**：
  - **特征工程**：对 R、F、M 进行长尾处理（`log1p` 对数转换），并使用 `StandardScaler` 进行标准化，消除量纲和极值对距离计算的影响。
  - **聚类建模**：基于 `scikit-learn` 的 K-Means 算法，将 9.3 万名用户聚类为 4 个群体。
  - **业务洞察**：
    - **重要价值客户**（频次高、金额高）：平台的中流砥柱。
    - **重要保持客户**（金额高、频次高，但很久未买）：流失风险大，需重点发大额优惠券召回。
    - **重要发展客户**（金额高、近期买过，但频次低）：潜力巨大，需交叉推荐促复购。
    - **一般挽留客户**（金额低、频次低、近期未买）：边缘人群，低成本触达即可。

## 📁 项目文件说明
- `import_ecommerce.py`：批量读取 9 张 CSV 并导入 MySQL 数据库。
- `analyze_ecommerce.py`：连接数据库，执行留存/复购 SQL 并进行 Python 可视化，以及 K-Means 聚类建模。
- `ecommerce_queries.sql`：本项目使用的所有核心 SQL（GMV、留存、纯 SQL 的 RFM 分层等）。
- `ecommerce_retention.png`：用户新增与累计复购趋势图。
- `rfm_clustering_3d.png`：基于 R、F、M 原始值的 3D 聚类散点图。
- `rfm_clustering_2d.png`：基于 R、M 维度的 2D 聚类散点图（更直观）。
