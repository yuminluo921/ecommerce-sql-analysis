# Olist 电商用户行为分析 (SQL + Python)

## 📖 项目背景
本项目基于巴西电商平台 Olist 的真实数据集（约 10 万条订单），使用 SQL 和 Python 完成完整的商业数据挖掘与分析工作流。目的是探索电商平台的销售趋势、用户复购行为以及留存表现。

## 🛠️ 技术栈
- **数据库**：MySQL, Navicat
- **编程语言**：Python 3 (Pandas, SQLAlchemy, Matplotlib, Seaborn)
- **核心技能**：多表 JOIN、CTE (WITH)、窗口函数、CASE WHEN 条件聚合、留存计算、数据可视化。

## 📊 数据清洗与导入
通过 Python 脚本 `import_ecommerce.py` 将 9 张 CSV 表（用户、订单、支付、商品、评价等）批量导入 MySQL 数据库。

## 🔍 核心业务分析结论

### 1. 每日 GMV 与销售趋势
通过订单表和支付表关联，计算每日成交总额。数据显示平台销售额在 2017-2018 年呈显著上升趋势。

### 2. 区域销售分布
计算各省份销售额排名，发现 **SP（圣保罗州）** 是 Olist 的核心市场，销售额遥遥领先。这也与巴西的人口和经济分布相符。

### 3. 用户留存与复购率洞察（核心业务点）
- **次日/7日留存率为 0%**：通过 SQL 计算真实自然人 ID (`customer_unique_id`) 的留存率，发现次日和7日留存率趋近于 0。
- **累计复购率约 3%**：放宽时间窗口后计算累计复购，发现仅约 3% 的用户会再次购买。
- **业务结论**：Olist 主营低频高客单价商品（家具、电器等），用户自然复购周期极长。因此，平台不宜追求“日活”，而应通过**提升客单价、拓展高频快消品类**或进行**交叉销售**来拉动增长。

## 📁 项目文件说明
- `import_ecommerce.py`：批量读取并导入 9 张 CSV 到 MySQL 数据库。
- `analyze_ecommerce.py`：连接数据库，执行 SQL 聚合查询并绘制可视化图表。
- `ecommerce_queries.sql`：本项目使用的所有 SQL 查询语句，包含 GMV、留存率、排名、复购率等核心逻辑。
- `ecommerce_retention.png`：用户新增与累计复购趋势图。
